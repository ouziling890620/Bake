# 小禾日和 | 手作烘焙的溫暖日常

一頁式手作烘焙坊展示網站，包含商品瀏覽、購物車與線上預訂功能。純前端實作，無需後端即可運行。

🔗 **線上預覽**：[https://ouziling890620.github.io/Bake/](https://ouziling890620.github.io/Bake/)

## 技術棧

- HTML5 / CSS3
- Vanilla JavaScript
- Google Fonts（Noto Sans TC）
- `localStorage`（購物車資料持久化）

## 功能特色

### 導覽 / RWD
- 響應式導覽列，手機版提供漢堡選單
- 錨點導覽：首頁 / 關於我們 / 預訂出爐美味

### 商品展示
- 依分類呈現商品：職人麵包、甜心蛋糕、手作餅乾、暖心包子
- 每項商品含圖片、名稱、描述、價格

### 購物車系統
- 加入購物車、數量增減控制
- 購物車視窗：同名商品自動合併計數、單項小計、總金額
- 單一品項刪除
- 資料存於 `localStorage`，重新整理或關閉瀏覽器不遺失

### 結帳流程
- 表單欄位：姓名、手機（僅限數字、限 10 碼）、取貨日期、取貨時段、備註
- 取貨日期限制為「明日起兩週內」
- 週三公休日自動檢查並阻擋送出
- 表單驗證（手機碼數、必填欄位）
- 送出後顯示訂單成功動畫，彙整訂單明細
- 送出成功後自動清空購物車與表單

### 互動細節
- 點擊頁面空白處自動關閉購物車視窗
- 加入購物車按鈕即時視覺回饋

## 本機執行

直接以瀏覽器開啟 `index.html` 即可，無需安裝任何套件或啟動伺服器。
